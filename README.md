# FGO ステータス自動計算機 for atwiki

atwikiのPukiWikiライクモードで使用する、FGOサーヴァント用のステータス計算機です。

## 主な機能

- 初期・最大HP/ATKの計算
- レアリティ別の霊基再臨・聖杯転臨値の計算
- 物理型・魔術型ATKへの対応
- ★0～★5への対応（★0の計算条件とレベル構成は★2と同じ）
- SW・SR・DR・N/A・N/Dの計算
- 宝具の「リチャージ量15％以下補正値」の参考表示
- 通常攻撃N/Aの手動補正と適正値注釈
- 通常攻撃用・宝具攻撃用N/Aの分離
- 既存のPukiWikiコードへ計算対象セルだけを自動反映
- 元のコードが空の場合、`servant_template.txt`から完成コード全体を新規生成
- No.・真名と、ボイス／モーションの参照ページ名を自動反映
- 特性一覧からの複数選択、特性ごとの再臨・霊衣限定表記、既存コードからの設定読み込み
- クラススキルの名称・アイコン・効果設定と、件数の追加・削除・並べ替え
- Skill1～3の名称・アイコン・CT・効果・強化後設定（アイコン未入力時はランクを除いたスキル名を使用）
- 保有スキルと宝具の第二／第三再臨以降の名称・アイコン・効果差分
- 宝具のルビ・正式名称・ランク・種別・効果設定
- 絆礼装の名称・効果アイコン・効果設定、および「自身がフィールドにいる間、」の有無
- 通常入力とatwiki直接記述を併用できる可変数の効果行
- 効果文へ自由入力したターン・回数・回数＋ターン表記を追加する入力補助
- Lv.／OC表記をOn／Offで切り替え、`[Lv](3T)<OC:効果UP>`の順へ自動整理
- クラススキル・保有スキル・宝具の効果プレビュー、折りたたみ、親項目への移動、グループ別の背景色
- 宝具カード・対象・強化段階に連動した通常攻撃倍率行と、Lv.／OC／固定倍率の特攻攻撃行
- 再臨差分ごとの宝具種類・Hit数設定と、隠しステータスへの通常行・差分行出力
- パラメーター表のランク文字と橙色ゲージを自動反映
- 結果セル、HP行、ATK行、N/A行、完成コードのコピー
- 入力内容と元コードの同一タブ内保存・ページ再読み込み時の復元

## atwikiへの設置方法（推奨）

1. 計算機を設置する新規ページを作成します。
2. 編集モードを「PukiWikiライクモード」にします。
3. ページの編集権限を「管理者のみ」にします。
4. `atwiki_page_code.txt` の内容をすべてコピーし、ページへ貼り付けます。
5. ページを保存します。

JSは公開GitHubリポジトリからjsDelivr経由で読み込みます。atwikiの`include_js`による外部ファイル検査を避けるため、公式ガイドに記載されている`javascript`プラグインの外部スクリプト読込形式を使用します。入力内容と元コードは同じタブでページを再読み込みした場合に復元されます。タブを閉じた後や別のタブでは復元されません。

設置コードは次のとおりです。

```text
*FGO ステータス自動計算機

&html(<div id="fgo-status-calculator"></div>)
#javascript(){{
<script type="text/javascript" src="https://cdn.jsdelivr.net/gh/siroihuman/fgo-status-calculator/v1.5.3/FGO_StatusCalculator_atwiki.js"></script>
}}
```

`#javascript`を使用するページは、編集権限を必ず「管理者のみ」にしてください。

## 使用方法

1. No.、真名、レアリティ、クラス、成長タイプなどを入力します。
2. コマンドカード枚数、各攻撃のHit数、パラメーターを入力します。
3. 該当する追加特性を選択します。必要な特性には、再臨段階や霊衣名の限定設定を追加します。サーヴァント・人型と、性別・方針・性格・相性・クラス由来の特性は自動入力されます。
4. クラススキル・保有スキル・宝具・絆礼装を編集する場合は、各設定欄へ名称・アイコン・効果を入力します。
5. 必要な場合だけN/Aの手動補正または通常・宝具N/Aの分離を有効にします。
6. 既存ページを更新する場合だけ、ページのコードを「元のコード」欄へ貼り付けます。新規作成の場合は空欄のままにします。
7. 「計算・コード反映」を押します。
8. 「反映後コードを一括コピー」を押します。
9. コピーした完成コードをサーヴァント編集ページへ貼り付けます。

元のコードが空の場合は、`servant_template.txt`の全体を使って新規コードを生成します。既存コードを貼り付けた場合は、管理対象外の独自特性などを維持しながら次の部分を自動更新します。

- ページ上部・基本情報のNo.と真名
- ボイス／モーションの編集リンクと`include_cache`のページ名
- Classアイコン、Rare、Cost、傾向、タイプ
- クラススキル節のクラスアイコン（コメントアウト行を含む）
- レアリティに応じた列設定・レベル見出し
- HP行・ATK行
- 成長タイプ、スター発生率、スター集中度
- Q/A/B/EX/宝具Hit数、DR
- 隠しステータスの宝具種別・色
- 相性・方針・性格・性別・クラスと、選択した特性
- 宝具表のCardセル（コメントアウトされたテンプレート行を含む）
- N/A、N/D
- 筋力・耐久・敏捷・魔力・幸運・宝具のパラメーター表
- 入力した場合のみ、クラススキル・保有スキル・宝具・絆礼装の各節

効果は1行ずつ追加します。数値形式として「数値なし」「固定値」「Lv.1～10」「宝具Lv.1～5」「OC1～5」を選択できます。複雑なセル結合や独自記述が必要な行は「特殊記述を使用」を有効にし、その行のatwikiコードを直接入力してください。効果行は追加・削除・上下移動ができます。

各効果欄では、ターン数と回数を数値で自由入力して`(3T)`、`(2回)`、`(2回・3T)`などを効果文の末尾へ追加できます。`[Lv]`・`[Lv:確率]`・`<OC:効果UP>`・`<OC:回数UP>`はOn／Offボタンで切り替えます。同じボタンをもう一度押すと解除され、同じ分類の別表記を押すと置き換わります。異なる順番で設定しても、完成表記は`[Lv](3T)<OC:効果UP>`の順へ自動整理されます。クラススキルではLv.／OC表記のボタンを表示せず、保有スキルでは`[Lv]`と`[Lv:確率]`だけを表示します。

入力中の効果は各スキル・宝具の上部に一覧表示されます。効果ごとの入力欄と第二／第三再臨差分はクリックで折りたため、各効果の「このスキルへ」「この宝具へ」ボタンで親項目の先頭へ移動できます。再臨差分内の効果からは、その再臨差分の先頭へ移動します。

クラススキルだけは項目数も追加・削除・上下移動できます。保有スキルはSkill1～3、宝具と絆礼装は各1枠で固定されています。保有スキルと宝具の再臨差分は第二再臨以降・第三再臨以降だけを設定でき、それぞれの再臨差分に独立した強化後も設定できます。第四再臨の設定はありません。

宝具の種類とHit数は「宝具設定」でまとめて設定します。第二／第三再臨差分では通常と異なる宝具種類・Hit数を選択でき、宝具表のカード背景も差分に合わせて変更されます。隠しステータスでは通常と差分を別の行へ出力し、宝具Hit数にもそれぞれのカード色を付けます。通常だけの場合も、宝具Hit数にはカード色が付きます。

宝具の効果では「通常効果」「宝具攻撃」「特攻攻撃」を選択できます。「宝具攻撃」は宝具種類からカード色と単体／全体を判定し、強化前・強化後のどちらかを選ぶと宝具Lv.1～5の攻撃倍率とカード補正表記を自動生成します。単体／全体だけを手動指定することもできます。直前の効果も同じ敵単体または敵全体を対象とする場合は、重複する対象表記を省いて`＆超強力な攻撃`または`＆強力な攻撃`と出力します。「特攻攻撃」は特攻対象を入力し、固定値・Lv.1～5・OC1～5から倍率形式を選択します。カード補正表記と、`[Lv]`または`<OC:特攻威力UP>`は自動生成されます。

例えば通常がArts補助・0Hit、差分がBuster全体・8Hitの場合は次の形になります。

```text
|BGCOLOR(#e6e6fa):相性|人|BGCOLOR(#e6e6fa):属性|BGCOLOR(#e6e6fa):方針|BGCOLOR(#e6e6fa):性格|BGCOLOR(#e6e6fa):性別|宝具|BGCOLOR(#9AF):補助Ａ|
|~|~|~|~|~|~|~|BGCOLOR(#F88):全体Ｂ|

|~|4|4|4|5|BGCOLOR(#9AF):0|DR&footnote(即死攻撃を受けた時の補正値。数値が低いほど死に難い。)|5.0|
|~|~|~|~|~|BGCOLOR(#F88):8|~|~|
```

各内容設定欄がすべて空の場合、その節の元コードは変更しません。いずれかを入力した節は、設定欄の内容を使って節全体を再生成します。

## N/Aについて

「適正N/A」は次の式で計算します。

```text
クラス基本値 × Arts枚数補正 × 魔力補正 ÷ Arts Hit数
```

「15％以下補正値」は次の式で計算し、参考値としてのみ表示します。

```text
15 ÷（宝具カード補正 × 宝具Hit数 × 対象数補正）
```

採用する通常攻撃N/Aを手動変更した場合は、PukiWikiコードへ適正値の脚注を自動追加します。

```text
0.51&footnote(適正値：0.86)
```

通常攻撃と宝具のN/Aを分けた場合は、通常攻撃用と宝具用を別セルへ出力します。

```text
|N/A&footnote(攻撃時のNP上昇基礎値)|>|>|>|0.55|0.12|N/D&footnote(攻撃を受けた際のNP上昇基礎値)|3.00|
```

特性欄では「サーヴァント / 人型」を常に設定し、選択した追加特性に加えて性別・方針・性格・相性・クラス名を「人型」の直後へ挿入します。性格は「狂・星・夏・花嫁」を含めて選択値をそのまま追加し、相性は「星」を含めて「○の力」として追加します。性別「-」は「性別不明」として追加します。アーチャー・ランサー・アサシン・シールダー・アヴェンジャー・フォーリナー・プリテンダーはクラス名を追加しません。チェックボックスの「基本」には、他の入力欄と重複しない「ギリシャ神話系男性」のみを表示し、チェックボックスの「追加属性」欄は表示しません。反映時は未使用の空欄を除去し、末尾へ余分な` / `を残しません。

画面の「入力した特性」には、反映後コードの特性欄へ出力される全特性を同じ順番で表示します。元のコードにだけ存在する独自特性も表示対象です。

選択した各特性には「再臨範囲」と任意の「霊衣名」を設定できます。全再臨・霊衣共通は従来どおり特性名だけを出力します。限定設定では、例えば次のように全角括弧内へ対象を追加します。

```text
サーヴァント / 超巨大（第三再臨） / 炎（第一・第二再臨） / バニー系（第二再臨・霊衣名）
```

再臨範囲は第一・第二・第三再臨の単独または2段階の組み合わせに対応します。「再臨なし（霊衣限定）」と霊衣名を設定すると`王（霊衣名）`、全再臨に加えて特定の霊衣を指定すると`王（全再臨・霊衣名）`の形になります。複数の霊衣名は「・」で区切って入力します。

既存コードを貼り付けると、一覧に含まれる特性と限定表記を読み取り、チェック状態と再臨・霊衣設定へ反映します。一覧にない独自特性は、そのまま保持します。

## ローカルで確認する方法

`FGO_StatusCalculator_standalone.html` と `FGO_StatusCalculator_atwiki.js` を同じフォルダーへ置いたまま、HTMLファイルを開くとatwikiへ設置する前に動作確認できます。

中核処理の自動テストは次のコマンドで実行できます。

```text
node test.js
```
